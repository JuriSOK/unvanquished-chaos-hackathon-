# Live demo script (for the H Company agent)

Everything is offline (local `devmap`, no server browser, no network).

1. Double-click **Unvanquished BUGGED** on the desktop (or `LAUNCH_BUGGED.bat`).
2. Wait for the map to load (~20-40 s with software rendering). The game automatically joins the
   **Humans** team and spawns the soldier with the default **SMG** (`rifle` internally) on the open-sky "23" landing pad of `plat23`.
   If the game window is not focused, click its title bar once.
3. Look around with the mouse, walk forward with **W**, aim at the hangar.
4. **Left-click once** (primary fire).
5. Observe what happens to the soldier and the first-person view, and describe it.
6. Recovery if needed: `/kill` in the console, left-click to open the spawn menu, click **SMG**; the soldier respawns
   on the same pad. Repeat from step 3.

Compare with **Unvanquished CLEAN**: the same actions just fire the SMG normally (bullet holes, ammo decreases).

Only one game instance runs at a time; each launcher closes the other variant first.
